# Contributing

Thanks for contributing! This guide covers how changes are proposed and
reviewed in this repository.

## How to propose a change

1. Create a branch from `main`
2. Commit your change with a clear message
3. Open a pull request into `main`
4. Request a review and take part in the discussion
5. Keep your branch up to date with `main` until it is merged

## Code style

Keep changes small and focused — one pull request per topic.
