# pr-flow-demo-2

Walkthrough of the pull request flow for new contributors.

This repository is a small sandbox used to walk new teammates through how we
propose changes on GitHub:

1. Branch off the default branch
2. Make a focused change and open a pull request
3. Review, discuss, and keep the branch up to date
4. Merge

There is an open pull request ready to be merged live during the onboarding
session — take a look around.

## Monday session agenda

1. Tour of this repository: branches, issues, and pull requests
2. Walk through the open pull request and its review
3. Merge the pull request live
4. Q&A
